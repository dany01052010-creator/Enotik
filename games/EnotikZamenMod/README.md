# Enotik-zamen-mod (Android)

Отдельное приложение: меню, выбор сервера Grand Mobile, паки с бэкапом и откатом, чат с командами.

## Как сделать пак
В любой папке на телефоне создайте папку `ПАКИ`, а в ней папку для каждого пака, например `ПАКИ/мой-пак/`.
Внутри пака файлы лежат с теми же путями, что в папке игры:
`ПАКИ/мой-пак/texture/gta3.img` заменит `texture/gta3.img` в игре.

## Как пользоваться
1. «Меню» - ввести номер сервера - «Выбрать сервер».
2. «Папка игры» - выбрать папку с файлами игры (системное окно Android).
3. «Папка с паками» - выбрать `ПАКИ`.
4. Нажать на пак в списке: применится. Нажать ещё раз: уберётся. «Откатить всё» возвращает оригиналы.
5. Чат внизу понимает: помощь, паки, применить N, убрать N, откат, статус, сервер N.

## Ограничения
- Это отдельное приложение, а не кнопка внутри игры.
- На Android 11 и новее системное окно выбора папки часто не даёт выбрать `Android/data`. Если файлы игры лежат там, обычное приложение их изменить не сможет.
- Чат - не ИИ, только команды.
- Изменение файлов клиента может нарушать правила Grand Mobile (риск бана). Меняйте только внешний вид.
