# Enotik Recorder

Запись экрана Android (10+) аппаратным кодеком: MediaProjection + MediaRecorder.
Файлы сохраняются в «Фильмы / Enotik Recorder». Остановка — кнопка в приложении или в шторке уведомлений.
Настройки: разрешение, FPS, качество, ориентация, микрофон, H.265.
Звук игры (внутренний) пока не пишется.
