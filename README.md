# FileDropper

Выбираешь файлы/папку (или шлёшь через «Поделиться») → выбираешь кнопку → файл ставится куда нужно.

## Как собрать APK
**Вариант 1 — Android Studio:** File → Open → папка FileDropper → Build → Build APK(s).
**Вариант 2 — с телефона/без Android Studio:** залей папку в GitHub-репозиторий, вкладка Actions → Build APK → скачай `FileDropper-debug-apk`.

## 4 действия
- ▶ Поставить файл — ставит выбранные файлы по выбранной кнопке
- ✚ Записать кнопку — сохраняет файлы + куда ставить + текст «когда ставить»
- 🗑 Удалить кнопку
- ✎ Когда ставить — текст и автозапуск

## Текст «когда ставить»
Читается мгновенно локальным разбором (без интернета, не нейросеть):
- «в папку files/mods» — подпапка назначения
- «не заменять, если файл есть» — не перезаписывать (иначе заменяет)

## Android/data
- Android ≤10: работает напрямую (дать «Доступ ко всем файлам»).
- Android 11–12: нужен доступ к папке через системный выбор или root.
- Android 13+: система блокирует; работает только с root. Для остальных — назначение «Папка на телефоне».
