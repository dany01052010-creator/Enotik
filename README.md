# ModHelper — помощник модератора игры

Чат со скриншотами, таблица нарушений, маленькое окно поверх игры, жалобы «по кадру», постоянная запись экрана с вырезкой клипов и перевод голоса в текст.

## Запуск (Windows)
1. Установи Python с python.org (при установке поставь галочку **Add Python to PATH**).
2. Распакуй папку и дважды щёлкни **start.bat** — он сам поставит библиотеки и откроет программу.
3. Во вкладке **Настройки** вставь API-ключ Anthropic (console.anthropic.com → API Keys) и нажми «Проверить связь».
4. Во вкладке **Правила** вставь правила и сроки наказаний (текстом, из .txt или скриншотом).

## Как пользоваться
| Действие | Как |
|---|---|
| Мини-окно поверх игры | **F9** или кнопка. Тянется мышью за заголовок. Кнопки в заголовке: ▦/▭ — таблица/узкая колонка, ● — свернуть в кружок, ✕ — спрятать |
| Закрыть причину в мини-окне | ✕ рядом с причиной (или рядом с ником — убрать игрока). В таблице запись остаётся, вернуть: «Показать/скрыть» |
| Жалоба | **F8**: экран замирает → вставь доказательство (Ctrl+V) и/или напиши ник → Enter → Claude пишет ник, пункт правил, причину и срок; запись попадает в таблицу и мини-окно, а клип последних 40 сек сохраняется |
| Чат | Ctrl+V — вставить скриншот, «Снять экран», «Файл». Ctrl+Enter — отправить. Найденные нарушения сами добавляются в таблицу |
| Запись экрана | Вкладка «Запись и голос» → «Запустить запись». Хранится последние N минут |
| Вырезать нарушение | «Нарушение было от 45 до 15 сек назад» → «Вырезать», или **F10** — последние 40 сек |
| Голос | Выбери устройство → «Слушать». Текст идёт в мини-окно и подаётся в анализ жалоб |

Данные лежат в `%APPDATA%\ModHelper` (настройки, таблица, клипы в папке `clips`).

## Важно знать
- Игра должна быть в режиме **«в окне» или «без рамки»**. Поверх настоящего полноэкранного режима мини-окно не видно.
- Видео записывается **без звука**; рядом с клипом сохраняется .txt с распознанной речью за этот отрезок.
- Чтобы слышать игроков, выбери устройство **«Стерео микшер»** (Windows: Звук → Запись → ПКМ → включить). Микрофон слышит только тебя. Распознавание речи идёт через интернет, и кто именно говорит, оно не определяет.
- Оверлеи, запись экрана и глобальные горячие клавиши иногда не нравятся античитам. Проверь правила своей игры/сервера. Запись голоса игроков — тоже по правилам сервера и закону твоей страны.
- Claude только подсказывает; решение о наказании принимаешь ты. Ники и пункты проверяй по скриншоту.
- Запись: 10 кадров/с при размере 0.5 даёт примерно 100–150 МБ на 10 минут.
